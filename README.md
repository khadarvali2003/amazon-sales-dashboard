Amazon Sales Analysis Dashboard
1️⃣ Project Title / Headline

Amazon Sales Performance Dashboard
An interactive Power BI dashboard designed to analyze sales performance, profitability, discount trends, and regional distribution across different customer segments and product categories.

2️⃣ Short Description / Purpose

This dashboard provides a comprehensive overview of Amazon’s sales performance across segments, regions, states, and product sub-categories. It enables business stakeholders to identify high-performing segments, profitable regions, and product trends to support strategic decision-making.

3️⃣ Tech Stack

The dashboard was built using:

📊 Power BI Desktop – Core visualization platform

🔄 Power Query – Data cleaning and transformation

🧠 DAX (Data Analysis Expressions) – Measures for Sales, Profit, Discount, Quantity, and KPIs

🗂 Data Modeling – Relationships between Orders, Customers, Products, and Geography

📁 File Format – .pbix (development) and .png (dashboard preview)

4️⃣ Data Source

Source: Sample Superstore / Amazon-style retail sales dataset

The dataset includes:

Order Date

Sales

Profit

Discount

Quantity

Segment (Consumer, Corporate, Home Office)

Category & Sub-Category

Region & State

Structured across transactional-level data enabling aggregation by region, segment, and product type.

5️⃣ Features / Highlights

Now this is the most important section. You must explain it in a business context — not just describe visuals.

🔹 Business Problem

E-commerce businesses generate large volumes of sales data daily. However:

Which customer segment drives maximum revenue?

Which region is most profitable?

Are high sales translating into high profit?

Which sub-categories contribute the most revenue?

How do discounts impact profitability?

Raw data cannot answer these quickly.

🔹 Goal of the Dashboard

To create a centralized, interactive analytical tool that:

Tracks overall business performance

Identifies profit-driving regions and segments

Detects low-margin categories

Supports data-driven pricing and inventory decisions
